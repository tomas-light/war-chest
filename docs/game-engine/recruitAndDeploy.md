# Наём и розыгрыш отряда

Эти действия работают в активной дуэли для 13 отрядов базовой игры:
Archer (лучник), Berserker (берсерк), Cavalry (кавалерия), Crossbowman
(арбалетчик), Ensign (знаменосец), Knight (рыцарь), Lancer (конный копейщик),
Light Cavalry (лёгкая кавалерия), Marshal (полководец), Pikeman (пикинёр),
Royal Guard (королевская стража), Swordsman (мечник) и Warrior Priest
(капеллан). Выбранный жетон руки задаёт возможные действия; движок возвращает
доступные цели. Также поддержан [Footman (пехотинец)](./footman.md) с лимитом
двух собственных юнитов на поле. Всего доступны 14 отрядов.
Mercenary и Scout остаются недоступны: их отличия требуют отдельных правил.

## Правила действий

**Наём (Recruit).** Любой жетон руки, в том числе
королевский, можно потратить закрыто в сброс. Игрок выбирает поддержанный отряд
со свободным жетоном в своём снабжении. Этот жетон уходит в сброс открыто.
Количество жетонов в снабжении уменьшается на один.

**Розыгрыш (Deploy).** Выбранный жетон должен принадлежать одному из
поддержанных отрядов. Игрок выбирает свободную контролируемую им точку на поле.
Жетон выходит из руки, а отряд появляется на этой точке. Для этих
отрядов второй юнит того же типа того же игрока на поле запрещён, кроме
пехотинца, у которого лимит равен двум. Проверка
находится в стратегии отряда: каждый класс в
`packages/game-engine/src/unitActionStrategies` наследует `StandardUnitStrategy`.
`FootmanStrategy` переопределяет лимит без изменения общего выбора цели.
Поддержка общих действий не включает остальные тактики и автоматические
способности карточек: они реализуются отдельно.

Оба действия тратят один жетон и завершают ход. Переход к следующему игроку,
завершение раунда и добор используют общий механизм с пасом.

## Выбор, черновик и подтверждение

После нажатия на жетон колесо включает действие, если у него есть хотя бы одна
допустимая цель. При найме игрок нажимает на доступный жетон непосредственно
в своём снабжении; при розыгрыше выбирает подсвеченную клетку. Сброс показывает
закрытые жетоны стопкой со счётчиком, а открыто нанятые жетоны — отдельно и
видимо для всех игроков. Выбранная цель сохраняется в одном приватном черновике
партии. Проекция сразу показывает изменение руки, сброса,
снабжения или поля. Она не выполняет случайный добор, поэтому отмена не
показывает будущие жетоны. Отмена удаляет черновик, не меняя игровую историю.

Подтверждение повторно проверяет команду движком против версии партии, создаёт
одно событие `TurnActionPerformed` и удаляет черновик. Событие содержит
подтверждённый battlefield для replay и восстановления после перезагрузки.
Другие игроки получают открытый нанятый жетон или появившийся отряд, но не
получают лицо жетона, потраченного закрыто. До подтверждения черновик доступен
только действующему игроку.

Real server хранит черновик в `game_turn_drafts`, fake backend — в отдельном
хранилище IndexedDB. Оба предоставляют операции чтения, сохранения, отмены и
подтверждения. Прямую отправку `PerformTurnAction` через игровой сокет сервер
отклоняет: подтверждение проходит через черновик.

Этот срез содержит одно основное действие на ход; тактика пехотинца содержит
два последовательных движения внутри одного действия. Запланированный
[черновик полного хода](../development-plan/uiMigration/turnDraft.md) с цепочкой
шагов, просмотром союзником и бесшовным подтверждением потребуется для
последующих способностей и командной игры.
