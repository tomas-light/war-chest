# Game engine

`@war-chest/game-engine` — общий TypeScript-пакет с игровой моделью, командами
и событиями. Он нужен серверу для проверки намерений игроков, а клиенту — для
восстановления безопасного представления игры и replay без второй реализации
той же логики.

Сейчас пакет реализует технический жизненный цикл и первые сценарии правил:
создание и подготовку игры, старт, приватные мешок/руку/сброс, королевский
жетон, пас одним жетоном, наём и розыгрыш четырёх отрядов, смену участника,
завершение раунда и добор. Также
работают отключение и возвращение игрока, сдача и завершение по reconnect
timeout. Остальные действия отрядов и победа по игровым условиям пока не
реализованы.

Согласованные правила подготовки партии описаны отдельно:
[дуэльный и командный форматы, состав игры](./gameModes.md) и
[Random, Draft, Elimination Draft](./cardSelection.md). Они учитывают
макеты и обсуждения 7–8 сентября 2026 года и уточнение от 9 сентября:
в обоих форматах действует общая реверсивная очередь выбора по одной карте;
в дуэли у каждого по четыре карты, в командной партии — по три. Это требования
к дальнейшей реализации, а не возможности текущего технического сценария.

## Что уже работает

- состояния `waiting`, `active` и `finished` только для существующей игры;
- отдельное создание первого события без искусственного начального состояния;
- команды присоединения, старта, паса, сдачи и технического завершения;
- наём и розыгрыш Light Cavalry, Cavalry, Crossbowman и Swordsman в дуэли;
- проверка очереди и состава из двух разных игроков;
- выбор и смена игроком свободного места до заполнения партии;
- актуальные составы команд `white` и `black` с момента создания партии;
- фиксация победившей команды при техническом завершении;
- состояния presence `connected`, `disconnected` и `defeated` с точным
  reconnect deadline;
- проверка disconnect, своевременного reconnect и поражения по таймауту;
- атомарная цепочка `PlayerDefeated` и `GameFinished` для server repository;
- зафиксированный snapshot feature flags в `GameCreated`;
- последовательные номера и версия формата событий;
- строгая runtime-валидация persisted `GameEventData`;
- детерминированное применение событий и восстановление состояния;
- отдельные представления игрока и зрителя;
- приватные руки, счётчики мешка и закрытые сбросы;
- детерминированные переход хода, завершение раунда и добор до трёх;
- восстановление клиентского представления из безопасных событий;
- нейтральное событие `ViewSequenceAdvanced` для будущих полностью скрытых
  изменений.

Пакет не зависит от React, Fastify, Socket.IO или базы данных. Он также ничего
не сохраняет сам: транзакция и доставка событий остаются ответственностью
сервера.

## Публичный API

Основной цикл строится вокруг функций восстановления и проверки команд:

| Функция                             | Назначение                                                                   |
| ----------------------------------- | ---------------------------------------------------------------------------- |
| `createGame(command)`               | Создаёт первый `GameCreated` без существующего `GameState`                   |
| `hydrateCommand(data)`              | Превращает `GameCommandData` во временный объект `DecidableCommand`          |
| `decide(state, playerId, command)`  | Проверяет команду и возвращает новые события либо пустой массив              |
| `parseGameEventData(value)`         | Проверяет persisted unknown-значение и возвращает строгий `GameEventData`    |
| `hydrateEvent(data)`                | Превращает проверенный `GameEventData` во временный объект `ApplicableEvent` |
| `applyEvent(state, event)`          | Применяет факт; для первого `GameCreated` принимает `null`                   |
| `restoreGame(events)`               | Собирает состояние из истории или возвращает `null` для пустой истории       |
| `createViewFor(state, viewer)`      | Создаёт безопасный полный snapshot для получателя                            |
| `createViewEventFor(event, viewer)` | Преобразует внутреннее событие для конкретного получателя                    |
| `hydrateViewEvent(data)`            | Превращает `GameViewEventData` во временный объект `ApplicableViewEvent`     |
| `applyViewEvent(view, event)`       | Применяет безопасный факт; первый `GameCreated` принимает вместе с `null`    |
| `restoreView(events)`               | Собирает представление или возвращает `null` для пустой истории              |
| `getTurnActionOptions(game, playerId, coinIndex)` | Возвращает доступные цели наёма и розыгрыша для выбранного жетона |
| `previewTurnAction(input)` | Строит проекцию черновика без случайного добора и записи игрового события |

Экспортируемые функции, константы и типы собраны в
[`packages/game-engine/src/index.ts`](../../packages/game-engine/src/index.ts).
