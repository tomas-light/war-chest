# База данных в Docker

PostgreSQL хранит пользователей, игры, участников и подтверждённые игровые события. Docker нужен, чтобы каждый разработчик запускал одинаковую локальную базу одной командой.

На первом этапе в Docker запускаем только базу. Сервер и клиент удобнее запускать локально с быстрым обновлением кода.

## Настройка окружения

В корне проекта понадобятся:

```text
compose.yaml
.env.example
```

В `compose.yaml` настраиваем:

- PostgreSQL с закреплённой версией образа;
- постоянный volume;
- healthcheck;
- локальный порт;
- имя базы, пользователя и пароль из переменных окружения.

Секреты не добавляем в Git. В `.env.example` оставляем только безопасный пример конфигурации.

## Схема данных

Минимальный набор таблиц:

### `users`

Идентичность пользователя, необходимая для участия в играх и просмотра личной истории.

### `games`

Основная запись игры:

- идентификатор;
- статус;
- текущая версия;
- время создания, старта и завершения.

### `game_participants`

Связывает пользователя с игрой:

- роль;
- место игрока;
- итоговый результат;
- время присоединения.

### `game_events`

Последовательный журнал подтверждённых событий:

- идентификатор события;
- игра;
- порядковый номер;
- тип;
- JSON-данные;
- время создания.

### `processed_commands`

Хранит идентификаторы обработанных команд и защищает от повторного применения хода после reconnect.

## Миграции

Для схемы и миграций используем Drizzle ORM. Нужны команды:

```text
yarn db:generate
yarn db:migrate
yarn db:seed
yarn db:studio
```

Обязательные ограничения:

- уникальный номер события внутри игры;
- уникальный идентификатор команды;
- уникальное место игрока внутри игры;
- внешние ключи на пользователей и игры;
- индексы для истории пользователя и загрузки событий игры.

## Критерии готовности

- `docker compose up -d` запускает здоровую базу;
- миграции применяются к пустой базе;
- повторный запуск миграций ничего не ломает;
- тестовые данные можно создать отдельной командой;
- сервер проверяет соединение при старте;
- удаление контейнера не удаляет данные из volume.
