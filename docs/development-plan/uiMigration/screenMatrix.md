# Матрица экранов и компонентов

Матрица фиксирует результат аудита этапа 0. Figma-фреймы задают композицию и
состояние, сервер — доступные данные и роль, а существующие React-компоненты
сохраняют поведение. Отсутствующее поведение реализуется на указанном этапе.
