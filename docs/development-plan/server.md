# Сервер

Серверный инфраструктурный этап завершён. Fastify принимает авторизованные
команды, `GameService` проверяет их через game engine, PostgreSQL атомарно
сохраняет события и проекции, а Socket.IO рассылает персональные обновления
только после commit.

Фактические контракты не дублируются в development plan:

- [обзор server](../server/README.md);
- [HTTP API](../server/http-api.md);
- [Socket.IO](../server/socket-io.md);
- [игровой runtime](../server/game-runtime/README.md);
- [конфигурация, startup и SPA hosting](../server/hosting.md).

## Оставшаяся работа

Следующее серверное изменение зависит от реализации полных правил в
`@war-chest/game-engine`. После согласования минимального игрового сценария
нужно заменить временные команды и события в transport-контрактах, сохранить
возможность безопасного replay версионированной истории и обновить
integration-тесты полного пути от команды до персональной рассылки.

Первый релиз по-прежнему рассчитан на один server process с активными играми в
памяти. Redis, распределённые блокировки и горизонтальное масштабирование не
входят в текущий план.
