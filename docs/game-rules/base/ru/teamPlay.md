# Командная игра 2×2

[Базовая игра](./README.md) · [English](../en/teamPlay.md) · Источник: PDF, с. 12–13.

## Подготовка и победа

Две команды по два игрока используют командную раскладку. У команды 8 маркеров
контроля и 3 стартовые точки; ещё 8 точек нейтральны. Побеждает вся команда,
когда одновременно контролирует 8 точек. Цель не 6 и не отдельный личный счёт.

Каждый игрок получает 3 разных отряда, личные снабжение, мешок, руку и сброс,
а также собственный королевский жетон. Начальный мешок — 7 жетонов.
Команда не объединяет личные ресурсы.

## Порядок игры и Draft

Игроки сидят/расположены в порядке, где союзники не соседствуют. Первый ход
делает владелец инициативы; далее — следующий игрок по фиксированному кругу.
Захват инициативы не меняет этот порядок в текущем раунде. Без руки игрок
пропускает очередь без оплаты, а союзник продолжает играть. Отдельного
выбывания из-за пустой руки или мешка нет.

Для Draft открывают 12 случайных карт, случайно определяют первую команду,
а она выбирает своего первого выбирающего. Нумерация ниже обозначает порядок
по кругу от него, не номера мест в интерфейсе. Карты выбираются так:
`1 → 2 → 3 → 4 → 4 → 3 → 2 → 1 → 2 → 3 → 4 → 1`.
Каждый получает 3 карты. Это не три одинаковых «змейки».

## Совместные действия и информация

- Оба союзника могут разыгрывать юнитов на любой свободной точке команды.
- Дружественные юниты для способностей включают юнитов союзника.
- Нельзя нанимать жетоны для союзника или из его снабжения.
- Нельзя перехватить инициативу у союзника; действуют общие ограничения
  перехвата за раунд.
- Обсуждение между союзниками должно быть открытым для остальных игроков.
  Это правило оригинальных PDF и не делает руки открытыми.

Цифровое исключение проекта, согласованное 17 сентября: общий приватный
черновик хода. Автор может менять его, союзник видит только для чтения;
противники и зрители получают лишь подтверждённые действия. Остальные правила
видимости ресурсов сохраняются. Исключение пока не реализовано; см.
[контракт черновика](../../../development-plan/uiMigration/turnDraft.md).
