# Раунд и ход

[Базовая игра](./README.md) · [English](../en/rounds.md) · Источник: PDF, с. 6–7, 9.

## Набор руки

В начале раунда каждый игрок случайно набирает из мешка 3 жетона, не показывая
их другим. Если для следующего жетона мешок пуст, верните в него весь сброс,
перемешайте и продолжите набор до трёх. Не возвращайте сброс раньше времени,
пока в мешке ещё есть жетоны. Если мешка и сброса вместе недостаточно,
возьмите столько, сколько возможно, включая ноль.

Та же процедура пополнения применяется, когда способность требует взять
жетон из пустого мешка. Жетоны на поле, в снабжении и устранённые жетоны
при этом в мешок не возвращаются.

## Последовательность ходов

Первым ходит владелец инициативы на начало раунда. В дуэли игроки чередуются;
в 2×2 действует постоянный круг с чередованием команд. Полученная в раунде
инициатива меняет первого игрока только в следующем раунде.

В свой ход выберите один жетон и одно допустимое основное действие.
Если оно вызывает дополнительные действия, полностью разрешите их,
включая обязательные шаги и решение о необязательных, до передачи хода.
Способность может позволить потратить больше одного жетона за этот ход.

Игрок без жетонов в руке пропускает свою очередь без оплаты. Это не выбытие.
Раунд заканчивается, когда ни у кого нет жетонов в руке и закончена текущая
цепочка действий. Затем начинается новый набор. Если до этого выполнено
условие победы, партия завершается немедленно.

## Закрытые действия

Любой жетон руки, включая королевский, можно сбросить закрыто для одного
из следующих действий:

- **Пас.** Ничего больше не происходит. Другие жетоны руки всё ещё можно
  использовать в последующие ходы.
- **Перехват инициативы.** Допустим, если инициативой владеет противник
  и вы не владели ею ранее в этом раунде. Следовательно, за раунд инициатива
  может перейти лишь один раз; начавшая с ней сторона не забирает её обратно.
  В 2×2 перехват у союзника запрещён.
- **Наём.** После оплаты выберите жетон одного из своих отрядов в своём
  снабжении, покажите всем и поместите его в свой сброс открыто. Тип оплаты
  не обязан совпадать с нанимаемым отрядом. Нельзя нанять отсутствующий
  в снабжении жетон. Он не попадает сразу в руку или на поле.
