# Setup

[Base game](./README.md) · [Русский](../ru/setup.md)

## Two-player game

Each player receives 4 different unit cards, 6 control markers and one Royal
Coin. Each controls 2 starting locations; other locations are neutral.
There are no units on the board yet. Use the two-player board layout.

For random selection, deal 4 random cards to each player. The
[recommended armies](./scenarios.md) may be used for a first game.
Determine starting initiative randomly, except when a scenario or the
drafting rule below explicitly determines it.

## Drafting instead of dealing

For a duel, reveal 8 random cards and randomly determine who drafts first.
That player takes one card; players then alternate taking two until the
first player receives the last remaining card. Individual picks follow
`1 → 2 → 2 → 1 → 1 → 2 → 2 → 1`.
The second drafter receives initiative to start the game. Each has 4 cards.

For four players, use 12 random cards and the order in the
[team rules](./teamPlay.md). Elimination Draft is not described in these PDFs;
it is a separately agreed project mode, not part of this base-game adaptation.

## Resources and beginning play

Place 2 coins of each selected unit type and 1 Royal Coin in your own bag:
9 coins for a duel, 7 for a team game. Remaining coins of your selected types
form your personal supply. Total coins of a type are specified on its card.
Before the first draw, hands and discard piles are empty and no coins have
been removed from the game.

Begin the first round by [drawing a hand](./rounds.md). Randomize bag contents;
an empty bag follows the same replenishment rule throughout the game.
