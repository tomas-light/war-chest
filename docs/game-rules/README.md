# Правила игры / Game rules

Текстовая адаптация правил базового War Chest для цифрового игрового стола.
Это описание настольных правил, а не заявление о доступности всех механик
в текущем приложении. Боевые действия внедряются в этапе 6 uiMigration.

Nobility, Siege и Nightfall пока недоступны в бою. Их правила будут отдельными
разделами после согласования источников и механик. Другие наборы, упомянутые
на внешнем сайте, автоматически в scope проекта не включаются.

## Принцип адаптации

Сохраняем стоимость, допустимость, порядок действий, случайность и видимость
информации. Убираем полиграфические ссылки «см. рисунок», переворачивание поля,
физическое размещение компонентов на столе и художественные вступления.
Исторические составы сохранены отдельно. Размещение жетона на поле,
открытый/закрытый сброс и постоянное удаление жетона — правила, а не декор.

Текст не заменяет карточки всех 16 отрядов: PDF содержит общие правила,
примеры и FAQ, но не полный текст каждой карты. Уточнения не превращаем
в выдуманные полные способности. Тексты карточек RU/EN в Figma — согласованный
источник UI; каждый отряд отдельно сверяется перед реализацией.
