# Локализация web-клиента

`apps/web` поддерживает русский и английский интерфейс через `i18next` и
`react-i18next`. Ресурсы принадлежат FSD-слайсам: компонент не обращается к
общему словарю интерфейса, если текст относится только к его слайсу.

Язык определяется в порядке `localStorage` → язык браузера → русский fallback.
Выбор в `LanguageSelector` применяется без перезагрузки, сохраняется под ключом
`war-chest-language` и обновляет атрибут `lang` корневого HTML-элемента.

## Основной сценарий

1. Добавить парные `i18n/en.json` и `i18n/ru.json` в каталог слайса.
2. Подключить namespace, равный пути слайса относительно `src`, и задать
   `keyPrefix` текущего компонента.
3. Выполнить `yarn workspace @war-chest/web locale:generate`.
4. Проверить оба языка и состояния ошибки в интерфейсе.
