# Web-клиент

`apps/web` — браузерное React-приложение War Chest. На 4 октября 2026 года
работают вход, лобби, подготовка 1×1/2×2, выбор карт базовой игры, настоящий
игровой стол, первые дуэльные действия, профили и список завершённых игр.
В development-сборке те же сценарии доступны через real/fake backend.
Полные правила боя и просмотр прошлого ещё не подключены.

Клиент всегда обращается к backend относительно своего origin. Обычные запросы
должны начинаться с `/api/`, Socket.IO использует `/api/socket.io`. В
development и preview эти пути проксирует Vite, а в production их вместе со SPA
обслуживает Fastify.

## Что уже работает

- React 19 и Vite 8;
- маршрутизация React Router в Declarative Mode;
- генерация URL через `nice-web-routes`;
- TanStack Query provider с общей конфигурацией запросов;
- загрузка сессии, защищённые маршруты и logout;
- вход через Google, Telegram и Yandex ID в real-режиме;
- seeded fake-пользователи и сессии из `@war-chest/fake-database`;
- HTTP API adapter для лобби и жизненного цикла игры;
- создание 1×1/2×2, выбор и смена свободного места, проверка полного состава,
  обмен местами создателем в дуэли и запуск;
- Random, Draft и Elimination Draft базовой игры с серверной очередью
  и автоматической выдачей последней карты;
- одно незавершённое участие на пользователя с возвратом в текущую игру из
  лобби;
- публичные аватары в шапке, карточках и игровых экранах;
- профиль текущего пользователя с настройкой имени и аватара, публичные профили
  других игроков и переходы по именам участников;
- отдельный экран завершённых игр пользователя с результатами, составами,
  cursor-пагинацией и переходом к выбранной партии;
- игровой стол с обеими раскладками, перспективами игрока/зрителя и ресурсами;
- цикл ресурсов и пас в дуэли;
- наём, розыгрыш и обычное перемещение
  [14 отрядов](../game-engine/recruitAndDeploy.md), включая два юнита
  пехотинца, через приватный черновик, отмену и подтверждение;
- [тактика пехотинца](../game-engine/footman.md) с выбором каждого юнита и
  манёвра в его колесе; сейчас доступны два последовательных движения;
- игровая шапка, колесо действий и лента очереди с курсорной подгрузкой
  завершённых ходов;
- единая кнопка открытия игры в лобби, выбор роли внутри ожидающей игры и
  автоматический режим зрителя для уже запущенной;
- live-обновление списка лобби через Socket.IO в real-режиме и `SharedWorker`
  в fake-режиме;
- IndexedDB fake adapter для того же сценария без server;
- общий `SharedWorker`, который последовательно обрабатывает fake-операции,
  связывает сессии с вкладками и владеет IndexedDB;
- Zustand-store активной игровой сессии;
- real Socket.IO connection, применение событий и синхронизация после пропуска;
- fake connection с безопасными snapshots через SharedWorker;
- чтение runtime feature flags в dev-панели и snapshot флагов в состоянии игры;
- development-панель с persisted-переключателем backend;
- SCSS и SCSS Modules;
- локализация интерфейса на русский и английский с выбором языка;
- unit-, component-, fake E2E- и real E2E-тесты.

## Что пока не работает

- атака, захват, усиление, перехват инициативы, способности, командный бой
  и победа по точкам;
- цепочки действий полного хода, просмотр черновика союзником и drag and drop;
- независимый просмотр прошлого, навигация по ходам и воспроизведение истории;
- просмотр завершённой партии: `GameHistoryPage` остаётся заглушкой;
- редактирование fake feature flags через dev-панель и общий application
  feature-flags provider при запуске приложения.
