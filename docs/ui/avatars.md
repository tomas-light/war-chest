# Аватары игроков

16 готовых аватаров загружаются одним запросом к прозрачному PNG-спрайту.
Один файл используется в профиле, выборе пресета, лобби, партии и истории.
Пользовательские загрузки получают отдельный URL через API.

## Источник и размеры

Источник — [DefaultUserAvatar в Figma](https://www.figma.com/design/3dryG8iK34xmpJF7HLYeau/War-Chest?node-id=588-4338).
Изображения находятся в `DefaultUserAvatarImage` (`588:4355`), отдельные
варианты — `588:4339`–`588:4354`. Порядок: слева направо, затем следующая строка.

В приложении используются размеры 32, 42 и 58 px для пользователя и 96 px
для выбора пресета. Ячейка спрайта 192×192 покрывает максимум при плотности
2×. Варианты Figma XL 128 и Original 256 сейчас не используются в приложении;
перед их подключением нужно пересмотреть разрешение спрайта.

Спрайт 768×768 содержит сетку 4×4 без промежутков. Цвета оптимизированы
до палитры из 256 значений, итоговый PNG сохранён в RGBA с alpha-каналом.
Круг и прозрачность приходят из исходников;
рамка, фон и свечение остаются CSS. Спрайт импортируется из `src`, поэтому
production-сборка добавляет хеш содержимого в имя файла. При обновлении
картинок браузер получает новый URL.

## Подключение и обновление

[`AVATAR_PRESETS`](../../packages/api-contracts/src/types.ts) задаёт допустимые
ID для real/fake API. База хранит ID в `users.avatar_preset_id`, публичные
ответы передают `avatarVersion: "preset:<id>"`. Значение `null` показывает
инициалы, пользовательская загрузка сохраняет прежнее поведение.

[`AvatarPresetImage`](../../apps/web/src/entities/user/ui/AvatarPresetImage.tsx)
вырезает ячейку спрайта по сгенерированному описанию. `UserAvatar` использует
его для пресетов и сохраняет доступное имя пользователя и fallback при ошибке
загрузки. Кнопки выбора имеют текстовое имя и `aria-pressed`.

Чтобы обновить изображения:

1. Выгрузи 16 оригинальных PNG 256×256 из Figma во временную папку. Назови
   файлы по ID из `AVATAR_PRESETS`: `pinkSmile.png`, `mintWink.png` и далее.
2. Выполни `yarn workspace @war-chest/web avatars:build <абсолютный путь к папке>`.
   В Windows запускай закреплённый Yarn через bundled Node по `AGENTS.md`.
3. Проверь alpha-канал итогового PNG, края всех ячеек, качество при 96 px,
   desktop/mobile и один запрос к спрайту. При изменении набора обнови также
   переводы названий и тест каталога.

В репозитории остаются только
[`avatarPresets.png`](../../apps/web/src/entities/user/assets/avatarPresets.png),
[`описание сетки`](../../apps/web/src/entities/user/assets/avatarPresets.json)
и [скрипт сборки](../../apps/web/tools/avatars/buildAvatarSprite.mjs).
Исходники и временные выгрузки хранятся вне приложения.
