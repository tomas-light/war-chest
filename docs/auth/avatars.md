# Аватары

Пакет сохраняет собственную нормализованную копию аватара, чтобы клиенты War
Chest не зависели от доступности домена OAuth-провайдера. URL принимается только
из проверенного профиля провайдера и никогда не сохраняется в базе.

## Загрузка

Перед каждым запросом, включая переход по redirect, пакет требует URL с
протоколом `https:` без username и password. Имя хоста разрешается через DNS;
загрузка запрещается, если хотя бы один адрес относится к loopback, private,
link-local, documentation, multicast или другим зарезервированным диапазонам
IPv4/IPv6. Это ограничивает SSRF через URL и redirect провайдера.

Разрешено не больше трёх redirect. Каждый запрос имеет таймаут из
`AUTH_AVATAR_FETCH_TIMEOUT_MS`. Ответ должен быть успешным, иметь тело и
Content-Type `image/jpeg`, `image/png` или `image/webp`; параметры после `;` в
заголовке не учитываются.

Если Content-Length присутствует, он должен состоять только из десятичных цифр
и не превышать `AUTH_AVATAR_MAX_SOURCE_BYTES`. Тот же лимит проверяется при
потоковом чтении, поэтому отсутствие или ложное значение заголовка не позволяет
загрузить файл большего размера.

## Нормализация и хранение

Sharp проверяет фактический формат изображения. Принимаются JPEG, PNG и WebP, а
максимальное число входных пикселей ограничено `512 × 512`. Изображение
автоматически поворачивается по метаданным, обрезается до квадрата с attention
crop, уменьшается до `AUTH_AVATAR_SIZE_PX × AUTH_AVATAR_SIZE_PX` и кодируется в
WebP.

От нормализованных байтов вычисляется SHA-256 hash в формате base64url. Если он
совпадает с сохранённым, запись не обновляется. Иначе содержимое, тип `image/webp`,
hash и время обновления записываются в `user_avatars`.

## Ошибки

Обновление аватара выполняется по принципу best effort: любая ошибка загрузки,
проверки или сохранения не отменяет успешный вход. Для существующего
пользователя прежний аватар остаётся в базе, а новый пользователь продолжает
работу без него.

`getAvatar(userId)` возвращает бинарное содержимое, Content-Type и hash либо
`null`. HTTP-маршрут, авторизация доступа и cache headers находятся вне пакета.
