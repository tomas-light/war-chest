# База данных

База данных — отдельная инфраструктурная граница War Chest. Пакет
`@war-chest/database` отвечает за форму постоянных данных и подключение к
PostgreSQL, но не содержит игровых сценариев, HTTP-маршрутов или правил игры.
Благодаря этому миграции и схема не зависят от устройства Fastify-приложения.

Для локальной разработки PostgreSQL запускается в Docker, а сервер и
инструменты Drizzle обращаются к нему через один конфигурационный механизм
пакета.

## Что реализовано

- PostgreSQL 17.5 в Docker Compose с healthcheck и именованным volume;
- строгая конфигурация из `env.yaml`, необязательного `env.local.yaml` и
  переменных процесса;
- восемь таблиц для пользователей, авторизации, игр, команд и событий;
- Drizzle relations, индексы, внешние ключи и проверки целостности;
- публичный клиент с проверкой соединения и явным закрытием пула;
- версионируемые SQL-миграции и идемпотентные seed-данные;
- обязательный SHA-256 `request_hash` для идентичности обработанной команды;
- корневые команды для запуска базы, миграций, seed и Drizzle Studio.

## Граница ответственности

Пакет экспортирует Drizzle-схему, типы строк и `createDatabase`. Репозитории,
которые загружают игру или атомарно сохраняют события конкретной команды,
должны находиться в `apps/server`: именно сервер знает границы прикладной
транзакции.

Пакет не импортирует `game-engine`, Fastify или Socket.IO. Server уже использует
этот client для startup-проверки, пользовательских запросов и игрового
репозитория. Правила, replay и transport по-прежнему остаются за пределами
пакета базы.
