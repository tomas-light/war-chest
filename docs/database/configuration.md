# Конфигурация и подключение

Пакет сам загружает параметры PostgreSQL при вызове `createDatabase()`. Серверу,
миграциям и seed-команде не нужно повторять URL подключения или настройки пула.

## Источники конфигурации

Значения объединяются простым переопределением в фиксированном порядке:

```text
packages/database/env.yaml
  < packages/database/env.local.yaml, если файл существует
  < одноимённые переменные процесса
```

Поддерживаются только три ключа:

| Ключ                 | Тип              | Назначение                                                 |
|----------------------|------------------|------------------------------------------------------------|
| `DATABASE_URL`       | string           | URL подключения с протоколом `postgres:` или `postgresql:` |
| `DATABASE_POOL_SIZE` | positive integer | Максимальное число соединений в пуле                       |
| `DATABASE_SSL`       | boolean          | Требовать SSL при подключении                              |

Конфигурация должна оставаться плоским YAML-объектом. Неизвестные ключи,
вложенные значения, неверный URL, неположительный размер пула и некорректный
boolean останавливают команду до подключения к базе.

`env.yaml` хранится в Git с безопасной конфигурацией localhost.
`env.local.yaml` предназначен для локальных переопределений и игнорируется Git.
На стенде локального файла нет: значения с наивысшим приоритетом передаются
процессу запуска.

## Docker Compose и конфигурация пакета

Корневой `.env` и файл `.env.example` относятся только к созданию контейнера:
они задают имя базы, пользователя, пароль и опубликованный порт. Эти значения
не читаются приложением автоматически.

`packages/database/env.yaml` описывает подключение Node.js-клиента. Если порт,
пользователь или пароль контейнера изменились, соответствующий
`DATABASE_URL` нужно переопределить через `packages/database/env.local.yaml`
или переменную процесса.

## Публичный API

Пакет создаёт postgres.js driver и типизированный Drizzle client:

```ts
import { createDatabase } from '@war-chest/database';

const connection = createDatabase();

try {
  await connection.checkConnection();

  await connection.database.transaction(async (transaction) => {
    // Репозиторий сервера выполняет связанные записи в одной транзакции.
  });
} finally {
  await connection.close();
}
```

Объект подключения содержит:

- `database` — Drizzle client со схемой и relations;
- `driver` — низкоуровневый postgres.js client для редких технических запросов;
- `checkConnection()` — запрос `select 1` для startup/health-проверки;
- `close()` — корректное завершение пула.

Схема, relations и выведенные Drizzle-типы также доступны из корневого экспорта
`@war-chest/database`.
